# Archived one-off scripts

68 scripts and log files that were run once, did their job, and were then
committed and left in `scripts/erp/` where they buried the 16 scripts that are
actually maintained. Moved here on 4 September 2026.

**These are history, not tools.** Nothing here is expected to run. Several were
written against a schema that has since changed and would fail or, worse,
half-succeed. Read them to understand what was done to the data and when; do not
execute them.

Git holds the full history either way, so anything here can be deleted whenever
its story stops being interesting.

The habit that produced them — reaching for a one-off script instead of building
a screen — is what cycle 2 of the Back Bar roadmap in Lifemaxxing (Domains/Cocktails/Back Bar) exists to end.
